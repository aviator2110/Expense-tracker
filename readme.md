# Django Личные расходы (Expense Tracker)

Приложение на Django для ведения учета личных финансов, контроля расходов и анализа трат. Проект разработан в рамках домашнего задания.

---

## 🚀 Основные возможности

1. **Управление расходами (CRUD):**
   - Добавление, просмотр, редактирование и удаление записей о расходах.
   - Отдельная страница подтверждения при удалении записи.
   - Автоматическое назначение текущего пользователя владельцем записи.

2. **Модель Expense:**
   Каждая запись содержит следующие поля:
   - Название расхода
   - Сумма
   - Категория (*Продукты, Транспорт, Обучение, Развлечения, Здоровье, Другое*)
   - Способ оплаты (*Наличные, Карта*)
   - Дата расхода
   - Комментарий (необязательно)
   - Дата создания записи (автоматически)
   - Владелец записи (автоматически)

3. **Валидация данных:**
   - Сумма расхода должна быть строго больше нуля.
   - Дата расхода не может находиться в будущем.
   - Название должно содержать минимум 3 символа (без учета краевых пробелов).
   - Ошибки валидации отображаются непосредственно рядом с соответствующими полями формы (`ModelForm`).

4. **Авторизация и безопасность:**
   - Регистрация, вход и выход пользователей.
   - Полная изоляция данных: пользователи могут работать только со своими записями.
   - Защита от несанкционированного доступа: попытка открыть чужую запись через прямой URL заблокирована.

5. **Поиск, фильтрация и сводка:**
   - Поиск по названию расхода.
   - Фильтрация по категории, способу оплаты и временному периоду (начальная и конечная даты).
   - Совместная работа всех фильтров с возможностью их быстрого сброса.
   - Динамическая сводка: отображение количества найденных записей и их общей суммы (с учетом примененных фильтров).

6. **Интерфейс и UX:**
   - Использование общего базового шаблона для всех страниц.
   - Сортировка по умолчанию: самые последние расходы отображаются первыми.
   - Уведомления (messages) об успешном выполнении операций (добавление, изменение, удаление).

## 🛠️ Установка и запуск проекта

1. Клонируйте репозиторий или перейдите в папку проекта:
   ```bash
   cd MyDjangoProject
   ```

2. Создайте и активируйте виртуальное окружение:
   ```bash
   python -m venv venv
   ```
   * Активация на Windows (cmd): `venv\Scripts\activate.bat`
   * Активация на Windows (PowerShell): `venv\Scripts\Activate.ps1`

3. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```

4. Примените миграции базы данных:
   ```bash
   python manage.py migrate
   ```

5. Запустите локальный сервер разработки:
   ```bash
   python manage.py runserver
   ```

6. Откройте в браузере ссылку: `http://127.0.0.1:8000/`

## 🔍 Проверка работоспособности
Для полноценного тестирования безопасности и фильтров рекомендуется:
1. Создать двух разных пользователей в системе.
2. Добавить по 5+ расходов для каждого пользователя.
3. Проверить, что пользователи не видят чужие записи (в т.ч. по прямым ссылкам).
4. Протестировать совместную работу фильтров поиска, категорий и дат.
